# 使用說明

DNS Manager 讓單位自行查看、清查、申請 DNS，並由系統管理員在後台審核後立即生效。本文依角色整理日常操作；權限細節見 [介面與權限](access-matrix.md)。

## 單位成員與單位管理員

側欄分為「日常作業」與「申請作業」兩組；左上角是目前單位（同時屬於多個單位時可在此切換），左下角是姓名、學號與角色。

| 工作 | 位置 | 步驟 |
| --- | --- | --- |
| 查看單位 DNS | 日常作業 › 單位 DNS | 列出歸屬本單位且目前生效的紀錄；上方公告進行中的清查活動。可依名稱、類型、解析內容或用途搜尋。 |
| 完成 DNS 清查 | 單位 DNS › 紀錄右側「清查」 | 更新申請人、電子郵件、分機與用途，在「清查備註」寫下確認結果，按「儲存並記錄清查」。系統記錄時間與經手人，不修改 DNS 解析。 |
| 申請新增 DNS | 申請作業 › 申請 DNS | 填申請人姓名、電子郵件、分機（申請單位自動帶入）；再填網域、名稱、類型、解析內容與用途後送出。狀態為「待審核」，核准前 DNS 不會變更。 |
| DNS 歸屬申請 | 申請作業 › DNS 歸屬申請 | 用於已存在但尚未歸屬任何單位的 DNS。填申請人資料，再填網域、名稱、類型與目前的解析內容及用途後送出。核准後歸屬本單位並記錄清查，解析內容不變；已有歸屬的紀錄須由管理員處理。 |
| 申請變更或刪除 | 單位 DNS › 「申請變更」／「申請刪除」 | 變更時填新的解析內容與原因（名稱、類型、TTL 不變）；刪除時寫明原因。都須經管理員核准才生效。 |
| 追蹤申請 | 申請作業 › 申請紀錄 | 查看本人與所屬單位的新增、歸屬、變更、刪除申請，狀態為待審核、已核准或未核准，並顯示管理員的審核回覆。 |
| 管理成員（單位管理員） | 日常作業 › 單位管理 | 按「新增使用者」輸入完整學號：已註冊者立即加入（預設為成員），未登入過的人會在第一次登入後自動加入。「管理權限」可調整角色或移出成員；單位至少保留一位管理員。 |

單位角色沒有 DNS 審核權限，所有申請由系統管理員審核。

## 系統管理員

側欄分為「日常作業」（單位 DNS、單位管理、DNS 管理）、「申請作業」、「審核作業」（申請審核）與「系統設定」（申請規則、刪除保護、郵件服務、清查活動、帳號管理、操作紀錄）四組，範圍涵蓋全部單位與網域。

| 工作 | 位置 | 步驟 |
| --- | --- | --- |
| 審核申請 | 審核作業 › 申請審核 | 依待審核、已核准、未核准、已取消分頁。展開一列查看申請類別、完整名稱、申請人、單位與用途。「核准」後填寫審核回覆並「核准並套用紀錄」，DNS 立即生效；標示「歸屬申請」者按「核准歸屬並記錄清查」，只改歸屬不改解析。資料不足時「不核准」並說明原因，申請人會在申請紀錄看到回覆。 |
| DNS 管理與歸屬 | 日常作業 › DNS 管理 | 依網域分頁列出所有解析值與申請人、單位、用途、清查狀態。「歸屬」指派所屬單位（只影響這一筆、不改解析）；「新增紀錄」直接建立並立即生效；「歷程」與「DNS 歷程（含已刪除）」查看變更經過；右上角可匯出全部 DNS CSV。 |
| 申請規則 | 系統設定 › 申請規則 | 勾選僅限系統管理員申請的 DNS 類型，未勾選的類型開放所有單位成員申請。所有網域皆開放申請：申請 PTR 時只列出反解網域，其他類型只列出正解網域。 |
| 單位管理 | 日常作業 › 單位管理 | 「建立單位」輸入名稱，可用學號指定已註冊的管理人；之後可改名，或在沒有成員、DNS 與待審申請時刪除。「指定單位管理人」授予管理權限。 |
| 刪除保護 | 系統設定 › 刪除保護 | 刪除 DNS 前須輸入刪除保護密碼，只有最高管理員能設定；未設定時所有刪除都會暫停。 |
| 清查活動 | 系統設定 › 清查活動 | 公告清查期間，單位使用者會在單位 DNS 頁面看到活動名稱與日期；同一時間只能有一個活動，日期以台北時間計算。 |
| 郵件服務 | 系統設定 › 郵件服務 | 「通知設定」啟用郵件服務並設定加密連線、寄件者與網管小組收件地址；「郵件模板」依情境（申請通知、審核結果、清查活動）個別啟用與編輯，右側即時預覽；「寄信給單位」勾選單位寄信給其管理員；「寄送紀錄」查看最近寄出的郵件。 |
| 帳號管理 | 系統設定 › 帳號管理 | 依單位分組列出帳號，可搜尋姓名、學號、電子郵件或單位；「管理」可編輯備註、調整角色或停用帳號，最高管理員帳號受額外保護。 |
| 操作紀錄 | 系統設定 › 操作紀錄 | 保存登入、申請、審核與 DNS 變更，只能查閱。可搜尋姓名或網域並依結果、操作類型篩選，展開列首箭頭查看請求資訊與變更前後內容。 |
