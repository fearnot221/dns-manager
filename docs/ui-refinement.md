## 共用規格

- Spacing：4／8／12／16／20／24／32／40／48px；邊框、圖示內距與光學偏移保留必要小值。
- Radius：小元素 6px、控制項 8px、面板 10px、對話框 12px。
- Accent：保留原綠色，用於主要操作、選取、連結與焦點。成功／警告／錯誤保留語意顏色，表面使用低比例混色。
- 非浮層不使用陰影；保留 loading skeleton 的既有漸層，不新增裝飾漸層。
- 保留既有隱藏捲軸偏好；寬表格仍使用可鍵盤聚焦、具名稱的 ScrollRegion。

## Responsive 程式碼檢查

| 寬度 | 適用佈局 |
| --- | --- |
| 1440px+ | 固定側欄、32px 頁面留白、最大內容寬 1520px |
| 1280px | 同一桌面殼層，欄位與工具列可收縮／換行 |
| 1024px | 24px 水平留白；單位選擇移至上方；申請人欄位兩欄 |
| 768px | 抽屜導覽；申請人欄位兩欄；工具列與宽表格不依賴頁面橫向捲動 |
| ≤600px | 44px 控制項、16px 頁面留白、對話框操作換行、請求列表改用手機配置 |
| ≤420px | 申請人與 DNS 欄位單欄，單位使用者列可換行 |

上述為 CSS／元件結構檢查，不代表實際瀏覽器截圖驗收。沒有開啟的應用程式瀏覽器分頁；依 AGENTS.md 未啟動 local demo 或其他服務，因此未完成各解析度、實際 focus trap、選單裁切、200% zoom 與觸控裝置的人工驗證。
