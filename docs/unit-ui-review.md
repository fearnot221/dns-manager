# 單位導向介面檢查與調整

## 導覽與名稱

| 入口 | 名稱 | 顯示範圍 |
| --- | --- | --- |
| `/dns` | 單位 DNS | 單位目前生效的 DNS；編輯者可提出變更申請 |
| `/requests/new` | 申請 DNS | 固定使用目前工作區的單位；無申請資格時先顯示說明 |
| `/requests` | 申請紀錄／申請審核 | 一般成員查看目前單位申請；管理員保留授權範圍內的審核清單 |
| `/units` | 單位管理 | 單位管理員與系統管理員；管理使用者及權限 |
| `/zones` | 網域管理 | 網域管理員與系統管理員 |
| `/inventory` | DNS 清查 | 網域管理員與系統管理員 |
| `/admin/application-policy` | 申請規則 | 網域管理員與系統管理員；全站規則仍限系統管理員 |
| `/admin/users` | 帳號管理 | 系統管理員 |
| `/activity` | 操作紀錄 | 系統管理員 |

導覽採平鋪功能清單，不再出現「個人工作區」「DNS 工作區」「我的 DNS」或「單位與共享 DNS」。只有具多個實際單位成員資格時顯示工作區切換；系統管理員可管理所有單位，但不會因此自動取得所有單位工作區。單一單位不再重複顯示單位選擇面板。

一般使用者登入後進入單位 DNS；管理員進入申請審核。切換工作區會回到該單位 DNS；未送出的申請沿用離開確認，避免將草稿誤送至其他單位。

## 檢查範圍與修正

- 共用導覽、登入落點、單位 DNS、單位管理、申請表及申請紀錄：統一角色與單位語意，分離有效 DNS 與申請進度。單位管理頁與管理資料 API 都檢查管理權限；管理資料不再依賴 PowerDNS 查詢。
- 網域清單、DNS 紀錄檢視、清查、申請規則、帳號及操作紀錄：檢查命名、返回連結、空清單、錯誤重試與載入提示；保留既有表格、檢視模式、篩選及角色邊界。
- 申請流程：使用目前單位，不重複要求選單位；沒有單位或編輯權限時先說明原因。申請規則載入失敗提供重試；清除申請篩選會同時重設範圍與狀態。
- 共用選單：補上 combobox 語意及作用中選項關聯；End 跳至最後可用選項；Escape 先關選單，避免同時關閉對話框；選取後回到觸發按鈕；長清單的鍵盤作用中項目保持可見。
- 響應式版面：沿用現有斷點與樣式。單一單位採全寬內容，側欄長單位名稱換行，單位操作保留觸控尺寸。清查載入狀態可被輔助技術讀取。

本次為原始碼與靜態渲染檢查。依專案規範未啟動 local demo，因此未宣稱完成實際瀏覽器、行動裝置或讀屏軟體的視覺／互動驗證。
